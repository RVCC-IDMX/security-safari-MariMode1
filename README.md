# SecurePoll

A polling and calculator web application built with Vite. 
This project demonstrates secure frontend development practices. 
That include protection against XSS, code injection, exposed secrets, and vulnerable dependencies.

---

## Features 

- Submit poll responses
- Simple expression calculator
- Secure handiling of user inputs
- Cleaned git history (removed secrets)

---

## Tech Stack

- Vite 
- Node .js
- PostCSS
- JavaScript
